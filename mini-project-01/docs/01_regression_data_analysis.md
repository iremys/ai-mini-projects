## 1. 데이터 탐색 (CP-01)

- **데이터 크기:** 17379행, 17열
- **결측값 및 중복 행:** 결측값 0개 / 중복 행 0개
  - 결측값이 없어 별도의 결측값 처리가 필요하지 않음
  - 중복 행이 없어 중복 데이터 제거 작업이 필요하지 않음
- **대여량(`cnt`) 분포의 특징:**  
  - 대여량이 적은 구간에 데이터가 집중되어 있으며, 대여량이 증가할수록 빈도가 점차 감소하는 우측 편향 분포를 보임
  - 일부 시간대에는 대여량이 800~900건 이상으로 나타나며, 최대 대여량은 977건임
  - 대여량의 분포가 균일하지 않아 예측 모델이 낮은 대여량 구간에 상대적으로 편향될 가능성이 있음
- **평균 대여량이 높은 시간대:** 
  - 17시: 약 461.45건
  - 18시: 약 425.51건
  - 8시: 약 359.01건
  - 16시: 약 311.98건
  - 19시: 약 311.52건

**분석:** 시간대별 대여량 그래프에서 발견한 특징을 1~2문장으로 작성합니다.  
- 전체 17,379건의 데이터에서 결측값과 중복 행이 없어 데이터 품질 측면에서 양호한 상태임
- 전체 대여량(`cnt`)은 낮은 구간에 데이터가 집중되고 높은 대여량으로 갈수록 빈도가 감소하는 우측 편향 분포를 보임
- 시간대별 평균 대여량은 출근 시간대인 7~8시와 퇴근 시간대인 17~18시에 높게 나타나며, 특히 17시에 가장 높은 평균 대여량을 기록함
- 새벽 시간대인 3~4시에는 평균 대여량이 매우 낮아 시간대에 따라 자전거 대여 수요에 뚜렷한 차이가 있음을 확인함
- 따라서 시간대(`hr`)는 대여량 예측에 중요한 특성이 될 것으로 판단됨

## 2. 데이터 분할 및 누수 확인 (CP-02)

- **Train:** 2011-01-01 ~ 2012-05-25 / 12,139건 / `cnt` 평균 159.72
- **Validation:** 2012-05-26 ~ 2012-09-11 / 2,616건 / `cnt` 평균 281.04
- **Test:** 2012-09-12 ~ 2012-12-31 / 2,624건 / `cnt` 평균 235.76
- **시간 순서로 분할한 이유:**
   * 실제로는 과거 데이터로 학습해 미래 수요를 예측하므로, 시간 순서를 그대로 지켜 나눠 평가함
   * 무작위로 섞으면 미래 데이터가 학습에 들어가 성능이 실제보다 좋게 나올 수 있음
   * 같은 날의 시간대가 서로 다른 집합에 섞이지 않도록 날짜 단위로 나눔
- **`casual + registered == cnt` 확인 결과:** True
  - 모든 행에서 `casual + registered`가 `cnt`와 같음
- **누수 가능성이 있어 제외한 특성과 이유:** `casual`, `registered`
  - 두 값을 더하면 정답인 `cnt`가 되므로, 입력으로 쓰면 정답을 미리 알려 주는 것과 같음
  - 실제 예측 시점에는 알 수 없는 값임

**분석:** 세 집합의 `cnt` 평균이 서로 다르다면, 그 차이가 이후 모델 평가에 어떤 영향을 줄지 1~2문장으로 작성합니다.  
- 평균이 Train 159.72, Validation 281.04, Test 235.76으로 달라, 세 집합이 다루는 기간(계절)에 따라 수요 수준이 다름
- 그래서 같은 모델이라도 평균이 높은 집합에서는 MAE, RMSE 같은 오차 값이 더 크게 나올 수 있으므로, 집합 간 오차를 그대로 비교하지 않고 같은 집합 안에서 모델끼리 비교해야 함
