## 4. 검색 성능에 대한 초기 가설 (CP-01)

- **가설 ① TF-IDF가 유리할 것으로 예상하는 질문 유형과 이유:** 
  
  **`-유리한 유형: 본문의 고유명사나 핵심 단어가 질문에 그대로 들어가 겹침 비율이 높은 질문`**  
  
  -QV004(그리스, 구제금융안, 재정지출 감축 규모)  
  -QV030(한·뉴질랜드 FTA, 정식서명 절차)  
  
  -이유: 다른 문서에 잘 안 나오는 단어가 정확히 겹칠 때 높은 점수를 주는 방식이기 때문

<br>
- **가설 ② BERT 기반 검색이 유리하거나 불리할 것으로 예상하는 질문 유형과 이유:**  
   
  
  **`-유리한 유형: 뜻은 같지만 다른 단어로 바뀌어 겹침 비율이 낮은 질문`**  
  
  -QV018(발표한 방책 -> 공표, 마법금지정책)   
  -QV046(싸움에 대비한 체육 -> 전투에 도움이 되는 실전 체육)  
  
  -유리한이유: 글자 일치가 아니라 문맥과 의미를 바탕으로 찾기 때문
  

  **`-불리한 유형: 생소한 고유명사나 특정 용어 하나를 정확히 맞춰야 하는 질문`**   
  
  -불리한 이유: 낯선 단어가 잘게 쪼개지거나 문단 전체 의미에 묻혀 TF-IDF보다 점수가 흐려질 수 있기 때문
