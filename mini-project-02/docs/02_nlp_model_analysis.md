## 1. 검색기 구현 및 임베딩 확인 (CP-02~CP-06, CP-08)

| 검색 방식 | 사용 모델·표현 방식 | 전체 문서 벡터 Shape |
|---|---|---|
| TF-IDF | 문자 2~3-gram, `max_features=30000` | `(200, 30000)` |
| BERT | `klue/bert-base` + Masked Mean Pooling | `(200, 768)` |
| Sentence-BERT | `snunlp/KR-SBERT-V40K-klueNLI-augSTS` | `(200, 768)` |


- **BERT Encoder 출력 / Attention Mask / Pooling 결과 Shape (CP-03~04의 질문 2개):**   
 `(2, T, 768)` / `(2, T)` / `(2, 768)`   *(T 최대 256)*
- **BERT와 Sentence-BERT의 최대 입력 길이:** `256토큰`
- **Padding을 평균 계산에서 제외하는 이유:**`패딩 토큰의 벡터까지 평균에 포함하면 실제 내용과 무관한 값이 섞여 문장 임베딩이 왜곡되기 때문`
- **BERT와 Sentence-BERT 문서 벡터를 혼합하지 않는 이유:** `두 모델은 학습 목적과 임베딩 공간이 다르므로, 차원(768)이 같더라도 동일한 모델로 생성한 질문,문서 벡터끼리만 비교함`
- **Pooling·코사인 유사도·검색 결과 검증 셀 실행 결과:** `모두통과`



## 2. 검색 평가 기준 (CP-07)

- **평가에 사용하는 검색 결과:** Top-5 문서
- **질문별 지정된 정답 문서 수:** 1개
- **Hit@1이 평가하는 내용:**  
  - 1위 검색 결과의 정답 일치 여부 확인
  - 전체 평균 시 첫 번째로 정답을 맞힌 비율
- **Recall@3이 평가하는 내용:**  
  - 상위 3개 검색 결과 내 정답 포함 여부 확인
  - 단일 정답 기준이므로 질문당 0 또는 1로 계산
- **MRR@5가 평가하는 내용:** 
  - 상위 5개 결과 내 정답 순위를 역순위(1/순위)로 환산
  - Top-5 밖이면 0으로 처리해 전체 평균 산출
- **검색 지표 단위 테스트 결과:**   
  - 1위(hit1=1), 2위(hit1=0, recall3=1, mrr5=0.5), Top-5 밖(mrr5=0) 계산 검증
  - CP-07 단위 테스트 정상 통과

## 3. 세 검색 방식의 성능 비교 (CP-07~CP-08)

`comparison_df`의 Validation 결과를 기록합니다.

| 검색 방식 | Hit@1 | Recall@3 | MRR@5 |
|---|---:|---:|---:|
| TF-IDF | `0.883` | `0.967` | `0.917` |
| BERT | `0.667` | `0.833` | `0.759` |
| Sentence-BERT | `0.767` | `0.883` | `0.821` |

**분석:** 지표별 성능 차이와 예상과 달랐던 결과가 있다면 그 가능 원인을 작성합니다.  

- **지표별 성능 비교 결과:**
  - Hit@1, Recall@3, MRR@5 세 지표 모두 TF-IDF > Sentence-BERT > BERT 순으로 나타남
  - 특히 TF-IDF는 Recall@3(0.967)에서 상위 3개 후보 안에 대부분의 정답 문서를 포함함

- **예상과 달랐던 결과 및 원인 (TF-IDF 1위):**
   - 딥러닝 기반 의미 검색 모델이 더 높을 것이라는 예상과 달리 문자 기반 TF-IDF가 최고 성능을 기록함
   - KLUE-MRC 특성상 질문에 본문의 고유명사와 핵심어가 그대로 포함되어 문자 2~3-gram 매칭이 매우 유리했기 때문임

- **BERT와 Sentence-BERT의 성능 차이 원인:**
   - 일반 BERT(Hit@1 0.667)는 문장 유사도 학습 없이 토큰 벡터를 단순 평균하여 문장 간 의미 구분이 약함
   - Sentence-BERT(Hit@1 0.767)는 문장 유사도 학습 덕분에 BERT보다 크게 향상되었으나, 고유명사 정확 매칭과 256토큰 제한으로 TF-IDF에는 미치지 못함

  - Test 문항 수(20개)가 적어 1문항 오답이 전체 점수에 0.05씩 크게 반영됨
